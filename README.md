# Homebrew tap

Install [favo-cli](https://github.com/irwinarruda/favo-cli), which keeps every AI subscription on every computer you own:

```sh
brew install irwinarruda/tap/favo-cli
```

The command you run is `favo`. Update it with `brew upgrade favo-cli`. favo's release workflow keeps the formula here up to date, so please send changes to [the main repo](https://github.com/irwinarruda/favo-cli).
