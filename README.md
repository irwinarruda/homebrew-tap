# Homebrew tap

Install [favo](https://github.com/irwinarruda/favo), which keeps every AI subscription on every computer you own:

```sh
brew install irwinarruda/tap/favo
```

Update it with `brew upgrade favo`. favo's release workflow keeps the formula here up to date, so please send changes to [the main repo](https://github.com/irwinarruda/favo).
